# Screenshots Directory

This folder contains screenshots used throughout the portfolio website
and QA documentation.

## Purpose

Store visual evidence from testing projects, including:

-   Application screens
-   Test execution evidence
-   Bug reproduction steps
-   API request/response screenshots
-   Newman execution results
-   GitHub Actions workflow results

## Suggested Structure

``` text
screenshots/
├── saucedemo/
├── parabank/
├── restful-booker/
└── website/
```

## Guidelines

-   Use descriptive filenames.
-   Highlight important UI elements when appropriate.
-   Compress images to keep the repository lightweight.
-   Keep screenshots organized by project.

## Notes

Only include screenshots that provide value to reviewers and recruiters.
