1. Purpose

This document provides a high-level overview of all API Test Cases created for the Restful Booker API Testing Project.

It serves as the central index for sprint-specific test case documentation.

Detailed API Test Cases are maintained in dedicated sprint documents.

2. Scope

This master document does not contain detailed API Test Cases.

Instead, it provides:

  • Sprint overview
  • Project progress
  • Test Case statistics
  • Repository structure
  • Documentation navigation
  • Traceability overview
