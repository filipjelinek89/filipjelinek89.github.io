Executive Summary

This document serves as the central defect register for the Restful Booker API Testing Project. It consolidates confirmed API defects into a single management report, providing traceability between endpoints, test scenarios, test cases and individual bug reports.

The purpose of this document is to provide QA engineers, developers and stakeholders with a high-level overview of the project's quality status.

Recommendations

  • Resolve High severity defects before release.
  • Repeat regression testing after fixes.
  • Extend negative API testing.
  • Add automated regression tests in Newman and GitHub Actions.
  • Validate JSON Schema for every endpoint.
  • Include security-focused API testing in future iterations.
