Purpose

This document provides traceability between the manual ParaBank test cases and their Playwright implementations.

The manual test design remains the business source of truth. This repository provides the automation implementation and execution evidence.

Mapping Rules

  • The manual Test Case ID is preserved in the automation filename.
  • One manual case maps to one automation specification wherever practical.
  • Data-driven demonstrations are additional framework examples and do not replace the mapped cases.
  • Application defects or environmental limitations are recorded through execution evidence and investigations.

Coverage Interpretation

100% automation coverage means that every planned manual test case TC001–TC070 has a corresponding automation specification. It does not mean that every execution result is expected to pass. Known application defects, misleading validation and environment limitations are preserved as QA findings.
