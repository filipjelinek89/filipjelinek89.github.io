Workflow

The repository contains .github/workflows/playwright.yml.

The workflow:

  1. Checks out the repository.
  2. Installs Node.js.
  3. Runs npm ci.
  4. Installs Playwright browsers and dependencies.
  5. Runs Playwright tests.
  6. Uploads the Playwright HTML report as an artifact when the job finishes.

Important Environment Constraint

The current Playwright configuration targets:

http://localhost:8081/parabank/

A GitHub-hosted runner does not automatically have the local ParaBank application. Therefore, the workflow is correctly configured as a CI workflow template, but a fully green remote run requires a ParaBank instance available to the runner.

Completion Interpretation

CI/CD configuration is complete for the current repository baseline. Making the application itself available in remote CI is an optional infrastructure enhancement.
