# Images Directory

This folder stores images used throughout the portfolio website.

## Examples

``` text
profile-photo.jpg
hero-background.jpg
project-banner.png
logo.png
```

## Guidelines

-   Use optimized images.
-   Prefer PNG for UI screenshots and logos.
-   Prefer JPG/WebP for photos.
-   Keep filenames lowercase with hyphens.
-   Compress large images before uploading.

## Notes

Avoid storing unnecessary or duplicate images. Only include files used
by the website.
